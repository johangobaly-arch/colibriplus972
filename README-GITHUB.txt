1. Créez un compte sur https://github.com

5. Créez le dépôt.
6. Cliquez sur Add file > Upload files.
7. Envoyez tous les fichiers contenus dans ce dossier.
8. Cliquez sur Commit changes.
9. Ouvrez Settings > Pages.
10. Dans Build and deployment :

    - Branch : main

Votre site sera disponible à une adresse du type :
https://VOTRE-NOM.github.io/colibriplus972/
